# 公网测试入口

按恒源云自定义服务要求，临时入口监听 0.0.0.0:8080；实现位于 backend/public_gateway.py，使用已存在的 FastAPI、HTTPX、Uvicorn，不新增依赖。

通过恒源云控制台“我的实例 → 当前实例 → 自定义服务”打开平台提供的地址，优先使用 HTTPS 地址。浏览器弹出认证框后输入独立测试账号。此账号允许操作整个测试工作台；凭据不写入源码、不复用 SSH 或数据库密码。

服务器凭据文件：/hy-tmp/codex-yolo-20261111/public-access.json，权限600。用户本机的独立凭据交付文件位于工作区 tmp/deliverables/yolo-web-public-test/访问信息.json，不属于本仓库。

请求链：公网8080认证入口 → 127.0.0.1:5186前端与API代理 → 127.0.0.1:8000后端。PostgreSQL保持127.0.0.1:5432。入口代理覆盖页面、静态资源、API和下载，去除认证头后才转发内部服务。

后台进程及命令记录在 /hy-tmp/codex-yolo-20261111/services.json 的 public_gateway 项；日志在 logs/public-gateway.log，关闭SSH终端后进程继续运行。实例重启后需重新启动内部服务和此入口。

启动命令（先确认8080没有现有入口，避免重复启动）：

```bash
cd /hy-tmp/yolo_web/backend
WORKBENCH_PUBLIC_CREDENTIALS=/hy-tmp/codex-yolo-20261111/public-access.json \
nohup /usr/local/miniconda3/envs/vision-platform/bin/python -B -m uvicorn \
  public_gateway:app --host 0.0.0.0 --port 8080 --no-access-log \
  > /hy-tmp/codex-yolo-20261111/logs/public-gateway.log 2>&1 < /dev/null &
```

检查监听：ss -lntp；停止时先读取services.json的public_gateway PID，核对其命令含public_gateway:app，再终止该进程即可关闭8080入口，内部服务继续运行。

已执行验证：代理专项测试3项通过；服务器监听0.0.0.0:8080；未认证及错误密码访问被拒绝；正确认证后页面、静态JS、API及查询参数正常；POST空导出请求返回后端422；部署包下载8,773,073字节且SHA-256与制品记录一致。8000、5186和5432仍只监听回环地址。

厂商公网地址由控制台提供；未取得该地址前不声称已从外部网络完成访问验收。该入口用于当前单用户测试，不具备多用户权限管理。
